# Демо: что показать, как записать и как установить на телефон

Всё, что нужно, чтобы за три минуты показать кейс человеку, который не знает
проекта, и чтобы у него самого получилось установить PWA.

## 1. Живой стенд

| Что | Где |
|---|---|
| Приложение | https://olivertwist95.clodocd.com |
| Хозяин | `host@staynest.demo` / `StayNest-Demo-2026` |
| Гость | `guest@staynest.demo` / `StayNest-Demo-2026` |
| Health | https://olivertwist95.clodocd.com/api/v1/health |

Демо-данные: 14 демо-домов в 4 городах и 13 броней в разных статусах. На стенде
может быть ещё ручное тестовое объявление — сид его не создаёт и не удаляет.
Почта уходит в Mailpit и смотрится через SSH-туннель (`docs/ops.md` §14);
демо-аккаунты уже подтверждены, регистрация для показа не нужна.

## 2. Сценарий на три минуты (руками)

1. **Каталог (30 с).** Открыть главную, выбрать даты, город и число гостей.
   Показать, что фильтры живут в URL: скопировать ссылку и открыть в новой
   вкладке — выдача та же.
2. **Карточка (30 с).** Открыть дом: галерея, удобства, правила. В календаре
   видно занятые ночи; при выборе диапазона появляется цена за период.
3. **Заявка (30 с).** Войти гостем, отправить заявку с сообщением. Показать
   экран «Заявка отправлена» и срок ответа.
4. **Хозяин (30 с).** Войти хозяином, открыть «Входящие заявки», подтвердить.
5. **Результат (30 с).** Вернуться гостем: статус `confirmed`, блок депозита,
   мок-страница оплаты (деньги не списываются).
6. **PWA (30 с).** Установить приложение, включить авиарежим, открыть
   «Избранное» и «Мои поездки» — данные читаются из кэша.

## 3. Видео 60–90 секунд

Готовый ролик можно записать двумя способами: автоматически (скрипт в
репозитории) или вручную с телефона. Автоматический тур на 61,6 секунды лежит
в репозитории (`docs/media/tour.mp4`) и покрывает весь продуктовый путь;
версию с озвучкой можно записать вручную и опубликовать ссылкой (YouTube
unlisted или GitHub Release).

### 3.1. Автоматическая запись

```bash
pnpm demo:tour        # пишет tmp/demo/tour.webm → docs/media/tour.mp4 и tour.gif
```

Скрипт Playwright проходит по стенду под демо-гостем и демо-хозяином (логин
готовится в отдельном контексте, чтобы экран входа не попадал в кадр),
записывает экран 1280×800 и конвертирует его через `linuxserver/ffmpeg` в
Docker. Получается тур на ~62 секунды: каталог → карточка → «Мои поездки» →
бронь → избранное → сводка хозяина → заявки → календарь → профиль. MP4 —
2,6 МБ (61,6 с), GIF (первые 32 с, ускорение ×2, 640 px) — 4,5 МБ, ~17 с.
Образ ffmpeg закреплён digest'ом, переопределяется переменной `FFMPEG_IMAGE`.
Требуется доступ к живому стенду и Docker.

### 3.2. Ручная запись с телефона (для портфолио)

| Время | Кадр | Действие |
|---|---|---|
| 0:00–0:08 | Каталог | Скролл карточек, видно цены и города |
| 0:08–0:15 | Фильтры | Выбор дат и города, обновление выдачи |
| 0:15–0:25 | Карточка | Галерея, календарь, цена за период |
| 0:25–0:35 | Заявка | Вход гостем, сообщение, «Отправить заявку» |
| 0:35–0:45 | Хозяин | «Входящие заявки» → «Подтвердить» |
| 0:45–0:55 | Гость | Статус `confirmed`, блок депозита, мок-оплата |
| 0:55–1:05 | Push | Уведомление на телефоне с установленным PWA |
| 1:05–1:15 | Офлайн | Авиарежим → «Избранное»/«Поездки» из кэша |
| 1:15–1:25 | Финал | Тёмная тема или экран установки, логотип |

Настройки записи: 1080×1920, 30 fps, без звука; телефон в режиме «Не
беспокоить», кроме кадра с push. Экспорт — H.264 MP4, до 15 МБ. Загрузить
на YouTube (unlisted) или в GitHub Release и вставить ссылку в README.

### 3.3. GIF для README

```bash
ffmpeg -i tour.mp4 -vf "fps=10,setpts=0.5*PTS,scale=640:-1:flags=lanczos,split[a][b];[a]palettegen=max_colors=128[p];[b][p]paletteuse" -loop 0 tour.gif
```

15–20 секунд при 640–800 px и палитре из 128 цветов дают 3–5 МБ (текущий тур:
~17 с, 640 px, 4,5 МБ). Если GIF тяжелее 5 МБ, уменьшить ширину до 560 px
или fps до 8.

## 4. Установка PWA на телефон

### Android (Chrome, Samsung Internet, Яндекс.Браузер)

1. Открыть https://olivertwist95.clodocd.com в Chrome.
2. Подождать пару секунд: снизу появится баннер «Установить приложение»
   (он показывается на втором визите или после первой заявки). Нажать
   «Установить».
3. Если баннера нет: меню ⋮ → **«Установить приложение»** (в старых версиях —
   «Добавить на главный экран»).
4. Иконка StayNest появится на рабочем столе; приложение откроется без адресной
   строки браузера.

### iPhone / iPad (только Safari)

1. Открыть сайт **в Safari** (Chrome на iOS не умеет устанавливать PWA).
2. Кнопка «Поделиться» (квадрат со стрелкой) → **«На экран «Домой»»** →
   «Добавить».
3. Запускать только с иконки на домашнем экране: в Safari push и офлайн-режим
   не работают так же, как в установленном приложении.
4. Web Push на iPhone доступен с iOS 16.4+ и только для установленного
   приложения: профиль → «Уведомления» → включить push (разрешение
   запрашивается по нажатию).

### Компьютер (Chrome / Edge)

Иконка установки в адресной строке справа, либо меню ⋮ → «Установить
StayNest». Приложение откроется в отдельном окне.

### Как проверить, что всё работает

- **Standalone:** нет адресной строки и вкладок, окно называется StayNest.
- **Офлайн:** включить авиарежим, открыть «Избранное» и «Мои поездки» —
  показываются ранее загруженные данные; каталог и карточки, открытые ранее,
  тоже доступны; кнопки, требующие сети, объясняют, что нужен интернет.
- **Push:** отправить заявку на свой дом вторым аккаунтом — на телефоне
  приходит уведомление (на iPhone — только для установленного PWA).
- **Обновление:** после деплоя в открытой вкладке появляется баннер
  «Доступна новая версия»; нажать «Обновить».

Если баннер установки не появился на Android, проверить: сайт открыт по HTTPS,
service worker зарегистрирован (`/sw.js`), приложение ещё не установлено и
баннер не был закрыт (закрытие скрывает его на 30 дней).
