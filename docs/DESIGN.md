# DESIGN: дизайн-система и экраны StayNest

Документ обязателен к чтению перед любой работой над интерфейсом (Сессии 4, 6–9, 12–16). Цель: интерфейс выглядит как продукт, а не как учебный шаблон, и одинаково хорошо работает на телефоне 360 px и на десктопе.

## 1. Направление
**Тёплый, спокойный, "природный" минимализм.** Ощущение: уютный дом у леса или озера. Много воздуха, крупные фотографии как главный визуальный элемент, сдержанный интерфейс вокруг них. Никаких градиентов-радуг, стеклянных эффектов ради эффектов и стоковых иллюстраций.

Принципы:
1. **Фото главные.** Интерфейс не конкурирует с фотографиями домов.
2. **Mobile-first.** Сначала проектируется экран 360×640, потом расширяется.
3. **Одно главное действие на экран**, выделено цветом акцента.
4. **Состояния важны так же, как "счастливый путь":** загрузка, пусто, ошибка, офлайн.
5. **Цена и даты всегда видны** там, где пользователь принимает решение.

## 2. Токены (CSS-переменные, Tailwind подключает их через конфиг)

| `--surface` | `#FFFFFF` | карточки, модалки, панели |
| `--surface-2` | `#F3EEE6` | вторичные поверхности, скелетоны |

| `--on-primary` | `#FFFFFF` | текст на primary |

**Производные токены для контраста (Сессия 4).** Чтобы границы полей и мелкий текст статусов проходили WCAG AA, в веб-реализации добавлены `--border-strong #8F8775` (границы интерактивных элементов), `--success-ink #256B43` и `--warning-ink #8A5A12` (текст бейджей). Базовые цвета не меняются; замеры пар — в `docs/design/contrast.md`.

### Цвета (тёмная тема, опционально в Сессии 16)
`--bg #141A17`, `--surface #1C2420`, `--surface-2 #26302B`, `--border #33403A`, `--ink #EDEAE3`, `--ink-muted #A3AEA7`, `--primary #5FB594`, `--on-primary #0E1512`, `--accent #F0A04B`. Тёмная тема включается по `prefers-color-scheme` и переключателем, токены меняются через `[data-theme="dark"]`.

### Статусы брони (цвет + иконка + текст, никогда только цвет)
| Статус | Цвет | Иконка (lucide) | Подпись ru |
|---|---|---|---|
| pending | warning | `Clock` | Ожидает ответа |
| confirmed | success | `CheckCircle2` | Подтверждено |
| declined | danger | `XCircle` | Отклонено |
| cancelled_by_guest / cancelled_by_host | ink-muted | `Ban` | Отменено |
| expired | ink-muted | `TimerOff` | Истекло |
| completed | info | `Flag` | Завершено |

### Типографика
- Заголовки: **Lora** (засечки, тёплый характер), 600. Текст и интерфейс: **Manrope**, 400/500/600. Обе имеют кириллицу. Шрифты **self-hosted** (пакеты `@fontsource`, только нужные начертания и subset `latin` + `cyrillic`), `font-display: swap`, системный запасной стек. Никаких запросов к внешним CDN: это ускоряет загрузку и работает офлайн.
- Шкала (мобильный / десктоп): `display 32/40`, `h1 28/36`, `h2 22/28`, `h3 18/24`, `body 16/24`, `small 14/20`, `caption 12/16`. Минимальный размер текста интерфейса 14 px, основного текста 16 px.
- Межстрочный интервал 1.5 у текста, 1.2–1.3 у заголовков. Длина строки в описаниях до 70 символов.
- Числа в ценах: табличные цифры (`font-variant-numeric: tabular-nums`).

### Отступы, радиусы, тени
- Базовая сетка 4 px. Шкала: 4, 8, 12, 16, 24, 32, 48, 64.
- Радиусы: `sm 8`, `md 12` (кнопки, поля), `lg 20` (карточки, модалки), `full` (бейджи, аватары).
- Тени мягкие, тёплые: `sm: 0 1px 2px rgba(31,42,36,.06)`, `md: 0 4px 16px rgba(31,42,36,.08)`, `lg: 0 12px 32px rgba(31,42,36,.12)`.
- Брейкпоинты: `sm 640`, `md 768`, `lg 1024`, `xl 1280`. Контейнер макс. 1200 px, боковые отступы 16 (мобильный) / 24 / 32.

### Движение
- Длительности: 120 мс (микро: hover, нажатие), 200 мс (появление элементов), 300 мс (bottom sheet, модалки). Кривая `ease-out`.
- Анимируем только `opacity` и `transform`. Никаких анимаций, меняющих размеры и раскладку.
- `prefers-reduced-motion: reduce` отключает всё, кроме смены цвета и прозрачности.
- Нельзя: параллакс, зацикленные анимации, мигание, скролл-хайджек.

### Иконки и изображения
- Иконки: `lucide-react`, толщина линии 1.75, размер 20 (интерфейс) и 24 (навигация). Иконка без подписи получает `aria-label`.
- Фото домов: соотношение 4:3 в карточках, 16:10 в галерее на десктопе, плейсхолдер blurhash, `loading="lazy"` (кроме первого экрана), `srcset` из трёх вариантов (400, 1000, 2000), `width` и `height` всегда заданы (нет скачков вёрстки).

## 3. Компоненты и состояния

Каждый компонент реализуется со всеми состояниями: `default`, `hover`, `focus-visible`, `active`, `disabled`, `loading`, `error` (где применимо). Минимальная область нажатия **44×44 px**.

| Компонент | Варианты и правила |
|---|---|
| Button | `primary`, `secondary` (контур), `ghost`, `danger`; размеры `md` (44 px), `lg` (52 px); состояние loading с неизменной шириной; иконка слева или справа |
| IconButton | 44×44, обязательный `aria-label` |
| Input, Textarea, Select | подпись всегда над полем (не placeholder), подсказка под полем, ошибка под полем с иконкой, счётчик символов где есть лимит |
| NumberStepper | для гостей, спален: кнопки −/+ 44 px, значение по центру |
| Checkbox, Radio, Switch, Chip | чипы для фильтров (мультивыбор), выбранный чип с галочкой |
| Badge | статусы, цвет + иконка + текст |
| Card (ListingCard) | фото 4:3, сердечко-избранное сверху справа (44 px), название (1–2 строки), город, характеристики, цена `от X ₽ / ночь`, при выбранных датах итог `X ₽ за N ночей` |
| Modal, BottomSheet | на мобильном BottomSheet, на десктопе модалка; ловушка фокуса, закрытие по Esc и по тапу на фон, возврат фокуса |
| Toast | `role="status"`, автозакрытие 5 с, ошибки не закрываются сами |
| Skeleton | повторяет форму контента, мягкая пульсация (отключается при reduced-motion) |
| EmptyState | иконка, заголовок, пояснение, одно действие |
| Calendar (DateRange) | см. раздел 4.4 |
| PhotoGallery | свайп, стрелки, индикатор "3 / 12", полноэкранный режим, клавиатура |
| PhotoUploader | сетка превью, прогресс по каждому файлу, перетаскивание порядка, метка "Обложка", удаление с подтверждением |
| Stepper (мастер) | прогресс шагов, текущий шаг выделен, доступный только вперёд при валидном шаге |
| BottomNav | 4 пункта, высота 56 px + safe-area |
| FavoriteButton | сердечко в карточке каталога и на странице дома, 44×44, `aria-pressed`, оптимистичное переключение |
| ModeSwitch | переключатель "Я ищу / Я сдаю" |
| StatusTimeline | события брони из `booking_events` |
| OfflineBanner, UpdateBanner, InstallBanner | см. раздел 6 |

## 4. Экраны

### 4.1 Навигация
- **Мобильный:** нижняя навигация. Режим "Я ищу": Поиск, Избранное, Поездки, Профиль. Режим "Я сдаю": Сводка (`/host`), Объявления, Заявки, Календарь; профиль открывается из аватара в шапке, поэтому пятый пункт не нужен. Колокольчик уведомлений в верхней панели.
- **Десктоп (от 1024 px):** верхняя панель с логотипом, строкой поиска, переключателем режима, колокольчиком, аватаром. Нижней навигации нет.

### 4.2 Главная и каталог
- Мобильный: сверху компактная строка поиска (город · даты · гости), под ней чипы быстрых фильтров с горизонтальной прокруткой, ниже одна колонка карточек. Кнопка "Фильтры" открывает BottomSheet на весь экран с кнопкой внизу "Показать N домов".
- Планшет: 2 колонки, десктоп: 3–4 колонки, фильтры слева постоянной панелью от 1024 px.
- Сортировка: выпадающий список справа над сеткой.
- Пусто: EmptyState "Ничего не найдено" с кнопкой "Сбросить фильтры" и подсказкой, какой фильтр сильнее всего сужает выдачу.
- Скелетоны на месте карточек, бесконечная прокрутка с кнопкой "Показать ещё" как запасным вариантом.

### 4.3 Карточка дома
- Мобильный: галерея на всю ширину (высота около 40% экрана), под ней название, город, ключевые характеристики (гости, спальни, кровати, ванные), описание со сворачиванием "Читать полностью", удобства сеткой иконок, правила, расположение (город и приблизительная область, точный адрес скрыт). **Липкая нижняя панель:** цена и кнопка "Выбрать даты" / "Забронировать".
- Десктоп: галерея-мозаика (1 большое + 4 малых), справа липкая карточка бронирования с календарём и расчётом.
- Сердечко избранного — в правом верхнем углу обложки карточки и рядом с названием на странице дома. Оно не вложено в ссылку карточки, имеет `aria-pressed` и не перекрывает цену и счётчик фото. Для анонима ведёт на вход с возвратом на ту же страницу.

### 4.4 Календарь выбора дат
- Два месяца рядом на десктопе, один на мобильном с вертикальной прокруткой месяцев в BottomSheet.
- Состояния дня: доступен, занят (зачёркнут, серый), выбран-начало, выбран-конец, внутри диапазона (светлый акцент), сегодня (контур), прошедший (приглушённый). Различие не только цветом: занятые зачёркнуты, начало и конец диапазона имеют скругления.
- Подсказка под календарём: "Минимум 2 ночи". При нарушении правила сообщение понятно объясняет причину, а не просто блокирует.
- Под календарём сразу расчёт: `N ночей × цена`, уборка, итог. Пока идёт запрос расчёта, показывается скелетон строки, а не прыжок вёрстки.
- Клавиатура: стрелки перемещают по дням, Enter выбирает, Esc закрывает. Каждая ячейка имеет `aria-label` вида "10 июля, доступно" или "11 июля, занято".

### 4.5 Мастер создания объявления
- 5 шагов, индикатор прогресса сверху, кнопки "Назад" и "Далее" в липкой нижней панели. Статус автосохранения ("Сохранено", "Сохраняю...", "Нет сети, сохраним позже") рядом с заголовком.
- Ошибки показываются под полями и сводкой на последнем шаге публикации (ссылки к проблемным полям).
- Шаг фото: большая зона перетаскивания, на телефоне кнопки "Сделать фото" и "Выбрать из галереи".
- Шаг цен: предпросмотр "Так цена будет выглядеть для гостя".

### 4.6 Бронирование (гость)
- Форма заявки: сводка (дом, даты, гости, цена), поле сообщения хозяину, блок "Как это работает" (3 строки: заявка, ответ в течение 24 ч, даты резервируются на время ответа), кнопка "Отправить заявку".
- Экран результата: статус `pending`, срок ответа, кнопки "Мои поездки" и "Искать дальше".
- "Мои поездки": вкладки "Предстоящие", "Прошлые", "Отменённые"; карточка брони с обложкой, датами, статусом (Badge), действием.
- Страница брони: StatusTimeline, контакты и адрес **после** подтверждения, кнопка отмены с подтверждением в BottomSheet.

### 4.7 Панель хозяина
- "Объявления": список с обложкой, статусом, числом заявок в ожидании (бейдж).
- "Заявки": вкладки по статусам, карточка с гостем, датами, суммой, сообщением, кнопками "Подтвердить" и "Отклонить" (отклонение с необязательным комментарием). Таймер "Осталось 5 ч" у pending, при менее 3 часов цвет warning.
- "Календарь": месячный вид выбранного объявления, цветовая легенда (заявка, подтверждено, блок), тап по свободной дате открывает BottomSheet "Заблокировать даты".
- "Сводка" (`/host`): 4 карточки крупными числами — заявок в ожидании, ближайший заезд, занятость 30 дней с прогресс-баром, доход за текущий месяц. Занятость считается по всем опубликованным домам хозяина: занятые ночи / (30 × число домов). Ниже SVG-столбцы дохода за 6 месяцев и список ближайших подтверждённых заездов со ссылкой на бронь. Заявки `pending` показаны отдельно, но в процент не входят.

### 4.8 Профиль и настройки
Имя, телефон, аватар, язык, тема, уведомления (переключатель push с пояснением, что запрос браузера появится после включения), выход.
- Блок аватара: круг 80 px, кнопка «Загрузить/Сменить фото», удаление, подсказка про форматы и 5 МБ.
- «Личные данные»: имя и телефон, сохранение через `PATCH /me`; телефон виден гостю только после подтверждения брони.
- Язык применяется сразу и сохраняется на сервере (`PATCH /me`), чтобы письма и push приходили на выбранном языке.
- «Пароль»: текущий и новый пароль, после смены все сессии завершаются и пользователь входит заново.

### 4.9 Служебные экраны
404, 500, нет сети, обновление приложения, вход и регистрация (одна колонка, крупные поля, показ пароля, автозаполнение браузера не блокировать).

## 5. Тексты и тон
Дружелюбно и коротко, на "вы", без канцелярита и без восклицательных знаков в ошибках. Ошибка всегда говорит, что случилось и что делать: "Эти даты только что заняли. Выберите другие даты". Все строки через i18n-ключи, длина английских вариантов учитывается в вёрстке (резерв +30%).

## 6. Дизайн PWA-специфики
- **Standalone:** в режиме установленного приложения нет адресной строки. Каждому экрану нужна своя кнопка "Назад" и понятная навигация, нельзя полагаться на браузерные кнопки.
- **Safe areas:** шапка и нижняя навигация учитывают `env(safe-area-inset-top/bottom)`, у корневого документа `viewport-fit=cover`.
- **theme-color** совпадает с цветом шапки (`--bg` светлая, `--bg` тёмная через `media`-вариант).
- **Нижняя навигация и липкие панели** не перекрывают контент: у страниц добавлен нижний отступ равный высоте панели.
- **Никаких hover-зависимых функций.** Всё доступно тапом.
- `overscroll-behavior: none` на корне, чтобы не было "резинового" эффекта и случайного обновления страницы.
- **Иконки приложения:** 192, 512, maskable 512 (значимая часть внутри центральных 80%), apple-touch-icon 180. Простой знак (домик-гнездо) на фоне `--primary`, без мелких деталей.
- **InstallBanner:** показывается не при первом визите, а после второго визита или после успешной отправки заявки; одна кнопка "Установить" и "Не сейчас" (не показывать 30 дней). На iOS вместо нативной кнопки показываем инструкцию "Поделиться → На экран «Домой»" в BottomSheet.
- **OfflineBanner:** тонкая полоса под шапкой "Нет сети. Показываем сохранённое", действия, требующие сети, получают disabled-состояние и подсказку причины.
- **UpdateBanner:** "Доступна новая версия" + кнопка "Обновить", не блокирует работу.
- **Скелетоны вместо спиннеров** при первой загрузке, оптимистичные обновления у избранного.
- Splash: фон `--bg` и логотип по центру (манифест), для iOS допускается набор `apple-touch-startup-image`, если останется время.

## 7. Доступность (минимум, обязателен)
- Контраст текста не ниже 4.5:1 (крупного 3:1), элементов интерфейса 3:1. Агент проверяет пары токенов инструментом и фиксирует результат в `docs/design/contrast.md`. Янтарь `--accent` не используется как цвет мелкого текста на светлом фоне.
- Видимое кольцо фокуса у всех интерактивных элементов, порядок табуляции совпадает с визуальным.
- Семантические теги (`button`, `nav`, `main`, `h1…h3` без пропуска уровней), landmark-регионы, `lang` на `html` обновляется при смене языка.
- Формы: `label` связан с полем, ошибки через `aria-describedby` и `aria-invalid`, сводка ошибок получает фокус после неудачной отправки.
- Динамические обновления (toast, счётчик уведомлений) через `aria-live`.
- Всё управляется клавиатурой, модалки ловят фокус, Esc закрывает.
- Масштаб текста до 200% без потери функций.

## 8. Чек-лист дизайн-ревью (применяется в конце каждой UI-сессии)
- [ ] Экран проверен на 360, 768 и 1280 px, нет горизонтального скролла
- [ ] Все цвета и размеры из токенов, нет "магических" значений
- [ ] Есть состояния: загрузка, пусто, ошибка, офлайн
- [ ] Области нажатия не меньше 44 px
