# LEARNS: журнал находок и граблей

Агент дописывает записи после каждой сессии в формате: `дата / сессия / что случилось / как решили / что делать в будущем`. Ниже стартовый список известных граблей, чтобы не наступать на них.

## Известные грабли (заранее)
- **iOS и push.** Web Push на iPhone работает только у PWA, добавленного на домашний экран, и запрос разрешения нужен по жесту пользователя. Проверять на реальном устройстве, симулятор не показателен.
- **Service worker и кэш.** Закэшированный `index.html` с устаревшими ссылками на чанки ломает приложение после деплоя. Нужны versioned-ассеты, `skipWaiting` только через баннер обновления, очистка старых кэшей.
- **Календарь и часовые пояса.** Не использовать `new Date('2026-07-10')` для дат проживания (сдвиг в UTC). Работать со строками `YYYY-MM-DD` или с `date-fns` без конвертации во время.
- **daterange нормализация.** Для типа `daterange` Postgres приводит диапазоны к форме `[)`. Не строить диапазон с `'[]'` для дат проживания.
- **EXCLUDE и btree_gist.** Без расширения `btree_gist` ограничение с `listing_id WITH =` не создастся.
- **Нарушение EXCLUDE** возвращает SQLSTATE `23P01`, а не `23505`.
- **SSE за прокси.** Нужны heartbeat и отключённая буферизация, иначе соединение рвётся. В Caddy использовать `flush_interval -1` для маршрута SSE.
- **sharp в Docker.** Использовать образ на glibc (debian/bookworm-slim) или проверить сборку на alpine; следить за версией libvips.
- **Тесты на Postgres.** Параллельный запуск тестовых файлов на одной базе даёт гонки: отдельная схема или база на воркер, либо последовательный запуск интеграционных тестов.
- **Cookie в dev.** Frontend и API на разных портах: настроить прокси Vite на `/api`, чтобы cookie были same-site.

## Журнал

### 2026-10-19 / Сессия 1 / фундамент
- **MinIO больше не раздаёт образы.** `minio/minio` удалён с Docker Hub, `quay.io/minio/minio` отдаёт 401. В dev и prod используем совместимый форк `pgsty/silo`, закреплённый по digest. Код работает через S3-клиент, поэтому замена образа не влияет на приложение. См. ADR-021.
- **pnpm 12 игнорирует `pnpm.onlyBuiltDependencies`.** Настройки переехали в `pnpm-workspace.yaml`, ключ `allowBuilds` — это mapping (`esbuild: true`), а не список. Иначе установка падает с `ERR_PNPM_IGNORED_BUILDS`. См. ADR-023.
- **TypeScript 7 и ESLint 10 опередили экосистему.** `typescript-eslint` требует TS `<6.1`, `eslint-plugin-jsx-a11y` 6.10 — ESLint `<=9`. Зафиксировали TS 5.9.3 и ESLint 9.39.5; обновлять после поддержки плагинами.
- **Vite 8 на Windows слушает только `::1`.** `localhost:5173` не открывался по IPv4. Помогает явный `server.host: '127.0.0.1'` в `vite.config.ts`.
- **Порты на машине разработчика заняты.** 5432 использует другой Postgres, 3000 — Grafana. Dev-порты: API 3100, Postgres 5433. См. ADR-022.
- **Docker Desktop не запускается сам.** Перед `pnpm infra:up` нужно открыть Docker Desktop и дождаться `docker info`. В CI Docker не нужен, тесты API не ходят в базу.
- **knip не видит динамические зависимости.** `pino-pretty` подключается строкой в `transport.target`, `tailwindcss` — через `@import` в CSS. Для pino-pretty добавлен `ignoreDependencies`, CSS добавлен в `project`, чтобы Tailwind определялся.
- **Проверка границ модулей.** Временный импорт `modules/health → modules/tempfoo/service.ts` ломает `pnpm depcheck` правилом `modules-only-via-index`; после удаления файлов проверка снова зелёная.
- **SSH: порядок Include важнее номера файла.** В `sshd_config` первый полученный параметр побеждает, поэтому override нужно называть `00-staynest.conf`, а не `99-...`, иначе `40-hosting.conf` оставит `PasswordAuthentication yes`.
- **UFW хранит правила хостинг-панели.** После очистки сервера в UFW остались порты ISPmanager (21, 25, 53, 110, 143, 993, 995, 1500–1501). `ufw reset` с последующим добавлением только 22/80/443 убирает лишнее.
- **Битый хук ISPmanager ломает networking.** `/etc/network/if-up.d/ispmgrfw` вызывает `iptables-restore` с несуществующим ipset. Удаление хука и `/etc/isp*.conf` убирает failed-юниты `networking` и `ifup@ens3`.
- **`pnpm audit` на старте чист.** После установки зависимостей известных уязвимостей уровня high нет.
- **Fastify-плагин инкапсулирует `setErrorHandler`.** Обработчик, зарегистрированный внутри плагина, не действует на маршруты соседних модулей: клиент получает дефолтный ответ Fastify с `error.message` (риск утечки DSN/SQL/PII). Обработчики 4xx/5xx и 404 нужно ставить на корневом инстансе в `app.ts`. Регрессия закрыта тестами на 500, битый JSON, 413 и доменный `AppError`.
- **`pg.Pool` без `pool.on('error')` роняет процесс.** При обрыве idle-соединения pool эмитит `error`, и без листенера Node завершает процесс. Добавлены листенер (логируем только `code`), `query_timeout`/`statement_timeout` и лог неудачного health-check.
- **Production-конфиг должен падать быстро.** В `NODE_ENV=production` без `DATABASE_URL` и `CORS_ORIGINS` API теперь не стартует, а не подхватывает dev-значения по умолчанию.
- **Node 24 умеет читать `.env` сам.** `process.loadEnvFile()` заменил зависимость `dotenv`; меньше пакетов в цепочке поставок.
- **`trustProxy` вынесен в env.** По умолчанию `false`; в проде включается только когда API доступен исключительно через Caddy.
