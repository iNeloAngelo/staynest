| `s12-booking-detail-768.png` | Страница брони на планшете, 768 px |
| `s12-booking-detail-1280.png` | Страница брони на десктопе: две колонки, таймлайн, 1280 px |
| `s12-host-requests-360.png` | «Входящие заявки»: pending, кнопки «Подтвердить» и «Отклонить», 360 px |
| `s12-host-requests-768.png` | «Входящие заявки» на планшете, 768 px |
| `s12-host-requests-1280.png` | «Входящие заявки» на десктопе, 1280 px |

Снимки сделаны Playwright на e2e-базе: хозяин создал и опубликовал дом,
гость отправил заявку, хозяин подтвердил. Для скриншота входящих заявок бронь
возвращена в `pending`, поэтому видны действия. Полностраничные снимки на
360 px сняты с временно скрытой фиксированной нижней навигацией (та же
методика, что в С5/С7): иначе она рисуется на высоте первого экрана и
накрывает таймлайн. Медиа загружены в локальный Silo под префикс
`listings/e2e/...`; в БД и тестовом сценарии фото создаются без реального
файла, поэтому это единственное отличие от e2e-прогона.
