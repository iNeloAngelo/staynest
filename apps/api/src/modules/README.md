# Модули API

Модуль — независимая область: `auth`, `users`, `listings`, `photos`, `pricing`,
`availability`, `catalog`, `bookings`, `notifications`, `favorites`, `dashboard`, `health`.

## Шаблон модуля

```
modules/<name>/
├─ index.ts       публичный интерфейс (единственное, что можно импортировать снаружи)
├─ routes.ts      HTTP: разбор запроса, вызов сервиса, ответ
├─ service.ts     бизнес-логика и транзакции
├─ repo.ts        SQL-запросы (Kysely)
├─ schemas.ts     zod-схемы входа и выхода
├─ events.ts      события модуля
├─ README.md      зачем модуль, публичный API, таблицы, события
└─ *.test.ts      тесты рядом с кодом
```

Правила:

1. Слои только вниз: `routes → service → repo`.
2. Другой модуль импортируется только через его `index.ts`.
3. `platform` не импортирует модули.
4. Чистая логика (расчёт цен, машина состояний) живёт отдельно от БД и тестируется без инфраструктуры.
5. Транзакция передаётся явно параметром `trx`.

Пример готового модуля — `health`.
