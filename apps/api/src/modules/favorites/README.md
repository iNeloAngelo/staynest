# Модуль favorites

## Зачем

Избранное гостя: добавить опубликованный дом, убрать его и получить список.
Модуль владеет таблицей `favorites`; карточки домов берёт через публичный
`catalog.summariesByIds`, поэтому приватные поля и DTO не дублируются.

## Публичный API

| Метод | Путь | Что делает |
|---|---|---|
| `GET` | `/me/favorites?cursor&limit` | список карточек с курсором `(created_at, listing_id)` |
| `GET` | `/me/favorites/ids` | идентификаторы опубликованных избранных домов для сердечек |
| `PUT` | `/me/favorites/:listingId` | идемпотентно добавить дом |
| `DELETE` | `/me/favorites/:listingId` | идемпотентно убрать дом |

`PUT` проверяет, что объявление опубликовано: черновик и архив дают
`404 listing_not_found`, как и несуществующий дом. `GET` отдаёт
`PublicListingSummary` без адреса и точных координат. `ids` ограничен 1000
записей, чтобы ответ для сердечек не рос бесконечно.

## Таблицы

`favorites` (`user_id`, `listing_id`, `created_at`, PK по паре). Миграции не
требовались: таблица создана в `0006_availability_and_misc`, индекс
`favorites_user_idx` покрывает выборку по пользователю.

## Как тестировать

```bash
pnpm --filter @staynest/api test
```

чужой черновик, изоляция пользователей, архив, курсор, невалидный UUID и 401.
