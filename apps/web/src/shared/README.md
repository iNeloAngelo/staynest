# Shared (web)

Общие, не зависящие от бизнеса вещи:

- `ui/` — компоненты дизайн-системы (Button, Input, Modal…), без бизнес-логики;
- `api/` — клиент API и обработка `application/problem+json`;
- `lib/` — даты, деньги, форматирование;
- `i18n/` — ключи и инициализация;
- `config/` — константы окружения.

`shared` не импортирует `features` и `pages`.
