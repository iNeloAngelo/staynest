# Фича catalog

## Зачем

Публичный каталог для гостя: поиск, фильтры, сортировка, бесконечная выдача и
карточка дома. Состояние фильтров живёт в URL, поэтому ссылка воспроизводит
выдачу (FR-S4). Данные сервера — только TanStack Query.

## Состав

| Путь | Ответственность |
|---|---|
| `api/catalog.ts` | запросы `GET /listings`, `GET /listings/:id`, `GET /cities` |
| `api/hooks.ts` | `useCatalog` (infinite), `useListing`, `useCitySuggestions` |
| `model/filters.ts` | разбор и сериализация фильтров URL, эффективная сортировка |
| `model/useCatalogFilters.ts` | связь фильтров с `useSearchParams` |
| `components/CatalogView.tsx` | страница-сборщик: поиск, фильтры, результаты |
| `components/CatalogFiltersPanel.tsx` | цена, гости, спальни, тип, удобства |
| `components/CatalogResults.tsx` | скелетоны, пусто, ошибка, сетка, «Показать ещё» |
| `components/ListingCard.tsx` | карточка в сетке |
| `components/ListingDetails.tsx` | карточка дома |
| `components/PhotoGallery.tsx` | мобильная карусель, мозаика на десктопе, лайтбокс |

## Поведение

- Фильтры пишутся в URL: `q`, `city`, `checkIn`, `checkOut`, `guests`,
  `priceMin`, `priceMax`, `bedroomsMin`, `type`, `amenities`, `sort`.
  Невалидные значения отбрасываются, неполный диапазон дат — целиком.
- Даты в поиске применяются по кнопке «Найти» и требуют обе даты. После
  ответа карточка показывает `stayPrice` — итог за период, а не цену за ночь;
  без дат остаётся цена за ночь.
- Цена в URL и в API — в копейках (`priceMax=750000` = 7 500 ₽). В полях
  фильтра пользователь вводит рубли, конвертация идёт через
  `minorToInput`/`inputToMinor`; компонентный тест проверяет оба направления.
- Пагинация курсорная; курсор не попадает в URL, потому что ссылка описывает
  фильтры, а не позицию прокрутки.
- Автоподгрузка работает через `IntersectionObserver`, кнопка «Показать ещё»
  остаётся запасным путём и видима всегда.
- Подсказки города — нативный `datalist` по `GET /cities?q=`; запрос уходит
  после двух символов, значение ввода откладывается через `useDeferredValue`.
- Публичная карточка не содержит адреса и точных координат: только город,
  регион и округлённые координаты.

## Доступность

- Поля фильтров сгруппированы в `fieldset`/`legend`, чипы используют
  `aria-pressed`.
- Карусель галереи переключается кнопками-стрелками (доступны с клавиатуры),
  у каждой ячейки есть `aria-label`; лайтбокс листается стрелками, закрывается
  по Esc и удерживает фокус.
- Состояния загрузки, пустой выдачи, ошибки и офлайна присутствуют.

## Как тестировать

```bash
pnpm --filter @staynest/web test
```

Юнит-тесты фильтров — `model/filters.test.ts`; сценарии каталога — в
`src/app/App.test.tsx`.
