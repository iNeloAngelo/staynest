# Фича listings (web)

## Зачем

Экран «Мои объявления» и базовая правка черновика для хозяина: список со
статусами, создание пустого черновика, сохранение полей, удобства, фотографии,
публикация со списком ошибок, архив и удаление черновика. Мастер из пяти шагов
заменит форму в Сессии 7, но контракты API и модель формы останутся.
Фотографии подключаются через публичный интерфейс фичи `photo-uploader`.

## Структура

```
features/listings/
├─ api/listings.ts        запросы к /me/listings, /listings, /amenities
├─ api/hooks.ts           TanStack Query и инвалидация списка
├─ components/            карточка, статус, секции формы, ошибки, редактор
├─ model/form.ts          форма ↔ UpdateListingInput, рубли ↔ копейки
├─ model/errors.ts        коды problem+json → i18n-ключи
├─ model/useListingEditor.ts  состояние и действия редактора
└─ index.ts               публичный интерфейс (только используемое снаружи)
```

## Публичный интерфейс

- `useMyListings`, `useCreateListing` — список и создание черновика;
- `MyListingCard` — карточка в списке;
- `ListingEditor` — форма и действия объявления;
- `listingsErrorKey` — перевод кода ошибки API.

Остальные хуки и компоненты используются внутри фичи и не экспортируются,
чтобы не расширять контракт раньше времени (knip это проверяет).

## Состояния

Список: скелетоны, пусто, ошибка с повтором, офлайн-предупреждение, кнопка
«Создать». Редактор: сохранение и публикация с блокировкой кнопок, ошибки полей,
сводка ошибок публикации, подтверждение архива и удаления в модалке.

## Тестирование

```bash
pnpm --filter @staynest/web test
```

`model/form.test.ts` проверяет преобразование денег и пустых полей,
`app/App.test.tsx` — список, создание черновика и ошибки публикации.
