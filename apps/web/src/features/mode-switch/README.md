# Фича mode-switch

Переключатель «Я ищу / Я сдаю». Один аккаунт и два режима (ADR-013): режим хранится
только на клиенте в `localStorage` (`staynest.mode`) и влияет на навигацию и тексты,
но не на права. Права на сервере выводятся из владения объектами.

Публичный интерфейс: `ModeProvider`, `useMode`, `ModeSwitchControl`, тип `AppMode`.
